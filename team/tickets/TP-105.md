# TP-105: "Needs attention" section at the top of the export

**Type:** Story · **Owner:** Jonas (FE) · **Points:** 3 · **Reviewer:** Rafi

## Story
As a tester pasting results into a ticket, I want the export to list failed and blocked cases first, with their notes, so that whoever reads it sees the problems without digging through every passing test.

## Acceptance criteria (DRAFT: finish in `/refinement TP-105`)
- Given a checklist with failed and blocked cases, when I export it, then a "Needs attention" section comes first, listing each failed and blocked case with its status and note.
- Given a checklist with no failed or blocked cases, when I export it, then the export says plainly that nothing needs attention.
- Given a note contains line breaks or markdown characters, when I export, then the markdown still reads correctly when pasted into a ticket.
- _Open: Does the full results table still list the failed and blocked cases again, or only once?_
- _Open: Should Not run cases appear in "Needs attention"?_
- _Dana's leaning (to confirm in refinement, not final): "Needs attention" lists only Failed and Blocked; Not run is unfinished work, not a problem, and TP-106's progress figure covers it. The full results table stays complete, so problem cases appear there too: the table is the full record._
