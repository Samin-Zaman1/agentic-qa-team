# TP-106: Show run progress next to the pass rate

**Type:** Story · **Owner:** Jonas (FE) · **Points:** 2 · **Reviewer:** Mei

## Story
As a tester mid-run, I want to see how much of the checklist I've actually run (for example "12 of 20 run, 60%"), so that I know how far along I am and a pass rate on a half-finished run doesn't mislead me or my lead.

## Acceptance criteria (DRAFT: finish in `/refinement TP-106`)
- Given a checklist with 20 cases of which 12 have a result other than Not run, when I view the summary, then it shows 12 of 20 run and 60% progress.
- Given a checklist with no test cases, when I view the summary or the export, then progress shows sensibly, with no error and no "NaN".
- Given I export the checklist, when I open the markdown, then the same progress figure appears in its summary.
- _Open: Does Blocked count as "run"?_
- _Open: How do we round progress (for example 1 of 3): the same way as the pass rate?_
- _Dana's leaning (to confirm in refinement, not final): Blocked counts as run, since the tester tried it and recorded a result; only Not run counts as "not run". Progress rounds exactly like the pass rate, so the two figures never disagree in style._

## Dev notes
Add the figure to the summary in `testpal/lib/report.js` (served by `GET /api/checklists/:id/summary`); Mei shows it on the page, so agree the field name with them early.
