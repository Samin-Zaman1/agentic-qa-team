# TP-103: Filter test cases by result

**Type:** Story · **Owner:** Mei (FE) · **Points:** 3 · **Reviewer:** Rafi

## Story
As a tester halfway through a long checklist, I want to show only the cases that are Not run, Failed or Blocked, so that I can find what's left to do or what needs a retest without scrolling past everything.

## Acceptance criteria (DRAFT: finish in `/refinement TP-103`)
- Given a checklist with cases in several states, when I choose the "Fail" filter, then only failed cases are listed and the page says how many are shown out of the total.
- Given a filter is on, when I change a case's result so it no longer matches, then the list updates in a way we agree on in refinement.
- Given a filter matches nothing, when I apply it, then I see a clear "no cases match" message and a way to clear the filter.
- _Open: When a case stops matching after I mark it, does it disappear right away or stay until I change the filter?_
- _Open: Can I pick more than one status at once (for example Fail and Blocked)?_
- _Open: Does the filter stay when I reload the page or switch checklists?_
