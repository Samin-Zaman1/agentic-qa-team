Run the daily standup. Samin doesn't attend. Include the current day from `team/office.json` in every brief.

1. Read `team/board.md` and the last entry in `team/standups.md`.
2. Launch `project-manager`, `be-dev`, `fe-dev-ui`, `fe-dev-reports` and `product-manager` in parallel. Each gives
   3 short lines (Yesterday / Today / Blockers) based on the board and their journal, without starting new work.
3. Ask `project-manager` to write the standup into `team/standups.md` and give short notes: one line per person,
   follow-ups and risks. Tomas doesn't ask Samin for an update.
4. Show Samin only Tomas's one-line notes.
